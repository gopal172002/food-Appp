# Food App

A Food Ordering Application designed to streamline the process of browsing, selecting, and ordering food online. This application provides a user-friendly React-based frontend, supports user authentication, and integrates with a backend API for order management. The system allows users to browse menus, add items to their cart, and place orders for delivery or pickup.

## Features

### Backend Features
- User authentication (sign up, sign in)
- Menu management (CRUD operations)
- Order management (create, view, and update orders)

### Frontend Features
- User-friendly interface built with React
- State management using Redux Toolkit
- Responsive Design for mobile and desktop views

- **React**: Frontend library
- **Redux Toolkit**: State management

## Setup Instructions

### Prerequisites
- Node.js and npm installed
- JWT Secret (for user authentication)
- MongoDB setup

### Backend Setup
1. Navigate to the backend folder:
    ```bash
    cd backend
    ```
2. Install dependencies:
    ```bash
    npm install
    ```
3. Create a `.env` file in the backend directory and add the following:
    ```env
    PORT=5000
    JWT_SECRET=your_jwt_secret
    MONGO_URI=your_mongo_connection_string
    ```
4. Start the server:
    ```bash
    npm start
    ```

### Frontend Setup
1. Navigate to the frontend folder:
    ```bash
    cd frontend
    ```
2. Install dependencies:
    ```bash
    npm install
    ```
3. Start the React development server:
    ```bash
    npm start
    ```
